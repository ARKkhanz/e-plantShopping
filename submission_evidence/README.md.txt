# e-plantShopping — Paradise Nursery

A React shopping application for Paradise Nursery.

## Features
- Landing page with a background image, company information and Get Started button.
- Five plant categories, each containing six plant cards.
- Redux Toolkit shopping cart with dynamic quantities and totals.
- Add to Cart buttons become disabled and show Added to Cart.
- Increase, decrease, delete, continue shopping and Coming Soon checkout.
- Responsive navigation to Home, Plants and Cart.

## Run locally
npm install
npm run build
npm run preview

## Deploy
npm run deploy

## Live application
https://ARKkhanz.github.io/e-plantShopping/

## Technology
React, React Redux, Redux Toolkit, Vite and GitHub Pages.
